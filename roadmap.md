# PETSCII Panic! — Roadmap

The current release is **v05**. How each version got here is in `devlog.md`.

## Done

- [x] The game in C64 BASIC V2: 5 lanes, 9 columns, 6 waves, four plants (peashooter, sunflower, wall-nut, cherry bomb) and three zombies (basic, conehead, buckethead)
- [x] Joystick or keyboard; Easy, Normal and Hard
- [x] HUD: sun meter and payout, seed bar colors, plant health, wave heads
- [x] One lawnmower per lane
- [x] Two versions: multicolor graphics (custom characters with animations) and the original PETSCII
- [x] Sound effects matched to recorded samples
- [x] Music: *Backyard Panic!*, on a second SID at $D420 when there is one; `.sid` files for PAL and NTSC
- [x] Volume keys: M/E with two SIDs, V with one
- [x] A PETSCII Pit-style menu with SID setup, instructions and credits; Q goes back to it from the games
- [x] Glyph showcase
- [x] Self-playing demos, multicolor and original PETSCII (v04, v05)
- [x] Scene trailers: full (machine code, with both games) and BASIC (v04, v05)
- [x] Version numbers on the disk and every program (v01)
- [x] Directory art in PETSCII Pit's style
- [x] Playable at [m0n.de](https://m0n.de/?disk=petscii-panic)
